## 一、 本层概述

Utils 层是整个项目的基础工具层，提供通用的工具函数、常量定义、国际化支持等。被 CLI 层、Core 层、Plugins 层广泛依赖。

**执行顺序（按依赖关系）**:
```
const.rs → fn.rs → i18n.rs → mod.rs
```
