# AST/代码 插件设计理念 (Code / AST Compression Plugin)

## 职责
由于语言众多，全量接入类似 `tree-sitter` 会极大增加编译时间和包体积，并不适合本工具 `TokenSlim` 的极简命令行定位。
然而，开发者在实际应用中经常要给大模型贴代码片段（如 JavaScript, CSS, HTML, C++）。这部分代码的特征是**含有大量无意义的注释和空格缩进**。

因此，代码 AST 压缩插件不需要做到真正的语法树级别的重构，而只需要通过正则或简单的分词技术实现以下目标：
1. **移除无用注释**（`//`, `/* */` 等）。
2. **剔除格式化空格**（只要不改变语义的换行或多余空格全部合并）。
3. **保留原语意**，使得模型可以轻松理解代码逻辑。

## MVP 设计
在目前的 Rust 命令行 MVP 中，提供一个通用的 `MinifyCodePlugin`，使用正则表达式执行轻度且无损的 CSS/JS 代码压缩：
- 去除 `/* ... */` 块注释。
- 去除 `// ...` 行注释。
- 将连续的大于 2 个空格替换为单空格或换行压缩。

注意：由于这是半有损操作（丢失了可读性），目前我们不打算实现完美地将代码格式化复原的机制，这更像一种“单向脱水”用于喂给 LLM。如果需要双向无损还原，建议不使用此类代码插件，而是使用 JSON/YAML 等具备严格 AST 结构的插件。
