# 插件名称：DotnetPlugin

## 1. 模块概述
针对 C# / .NET 生态设计的插件。主要处理 MSBuild 的冗长构建输出以及 .NET 深度异常堆栈。

## 2. 功能点清单
### 2.1 MSBuild 输出折叠
- **功能描述**: 识别并简化编译成功/失败的摘要信息，保留关键错误码（如 `CS0103`）。

### 2.2 .NET 堆栈深度清理
- **功能描述**: 自动识别并折叠 `System.Threading.Tasks`, `System.Runtime` 等系统库内部的冗长调用栈，仅保留业务代码帧。

### 2.3 路径令牌化
- **功能描述**: 对 `C:\Users\...\AppData\Local\Temp\...` 等复杂临时路径进字典化。
