# SmartCode Plugin 模块设计 (智能代码无损压缩插件)

## 职责
由于语言的 AST 解析器（如 tree-sitter）过于庞大，我们采用一种**基于词法分析的通用词元提取（Lexical Tokenization）策略**来实现对 Top 10 编程语言源代码的**双向无损压缩与还原**。
它特别适合处理类似 Java, C#, TypeScript 中动辄三四十个字符的超长类名、方法名和变量名，以及代码中大量的缩进空格。

## 策略
在不破坏任何结构、不误删任何注释和字符串常量的前提下，进行智能字典化和折叠：
1. **长标识符字典化**: 匹配所有长度大于等于 8 的单词（`[a-zA-Z_]\w{7,}`），并且不是标准语言关键字的，动态提取到 `DictionaryEngine` 中，替换为极短的占位符（例如 `$C12`）。
2. **多余空格编码**: 将行首或行内连续出现的 2 个以上的空格（如缩进）编码为 `$S|N`（例如 4 个空格变成 `$S|4`），这样能在不丢失格式的前提下省去大量多余字符 Token。
3. **保留原貌**: 字符串内部和特殊符号保持绝对原样。压缩后的文本再发给 AI，由于 AI 能理解这些自定义标记（特别是我们在 prompt 中声明过），它可以处理逻辑，等返回后再由系统无损还原。

## 数据结构
```rust
struct SmartCodePlugin {
    name: &'static str,
    priority: u8,
    identifier_pattern: regex::Regex,
    spaces_pattern: regex::Regex,
}
```

## 注意事项
这是一种**词法级别的通用压缩**，它不需要理解复杂的语法树，因此能以极高的性能处理 Python, Java, C++, JS, PHP, Go, Rust 等所有基于英语单词的源文件。
